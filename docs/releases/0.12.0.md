# Moxcrew 0.12.0 — Public Preview

Turn one goal into an inspectable AI crew—now as a native installer for macOS
and Linux.

## What is inside

- A redesigned conversation-first native workbench with a distinctive Moxcrew
  visual system.
- Inspectable plans, crews, tasks, memory, decisions and output workflows.
- Local-first operation with optional Codex, Claude Code and Gemini CLI
  connections using your existing provider access.
- English and Turkish interfaces, light and dark themes, and reduced motion.
- Native packages without Node, WebView2 or WebKit runtime dependencies.

## Install

Choose the DMG for your Mac architecture or AppImage/Deb for Linux x64 or ARM64
from the assets below. Verify the installer against `SHA256SUMS.txt` before
opening it.

This is an unsigned public preview and is not Apple-notarized, so Gatekeeper may
ask for explicit review. Use Finder's **Open** / macOS **Open Anyway** only after
verifying the checksum. Do not disable an OS security feature.

Provider CLIs and their accounts are installed separately. Moxcrew does not
resell model tokens and needs no Moxcrew account for local use.

## Before upgrading

Quit every Moxcrew or older Patchfleet process and back up the stopped data
directory. The app keeps the existing `com.patchfleet.desktop` bundle identity,
`patchfleet-desktop` executable compatibility name and canonical data location.
Do not run an old and new build as simultaneous writers.

## Public Preview limits

- macOS notarization is not included.
- Windows installers are withheld: the experimental lane still has unresolved
  private-storage ACL/locking and native behavior failures.
- Live-provider entitlement, output quality and every production capability are
  not guaranteed by the deterministic CI suite.
- Moxcrew Cloud is optional and no hosted service is bundled with this release.
