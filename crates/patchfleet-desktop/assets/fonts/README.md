# Bundled UI fonts

Manrope by the Manrope Project Authors, SIL Open Font License 1.1 (OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/manrope

Static weight450 and650 instances of Manrope[wght].ttf, subset to Latin,
Latin extended (including Turkish), general punctuation and currency symbols.
Generated with fontTools; egui's existing fonts cover remaining symbols.
Both fonts are bundled; no network or system-font dependency at runtime.
