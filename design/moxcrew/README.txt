MOXCREW / BRAND SOURCE / V1 / 2026-10-18

Product: Moxcrew = Mox + crew. Mascot: Mox. Brand domain: moxcrew.com.
Promise: Your AI team. On it.
Mox is the character; crew expresses a cooperating team and community spirit.
This identity does not add a new multi-user feature.

The owner selected concept 4: cobalt rectangular helper, asymmetric cream eyes,
orange eye ring and top tab. The original tactile PNG is reused unchanged.
Use it for welcome/first-use/marketing; use the flat SVG symbol in dense chrome.
SVG wordmarks contain Manrope 650 outlines and require no installed font.
Fonts and SIL OFL are in crates/patchfleet-desktop/assets/fonts.
The original ImageGen prompts are preserved verbatim in source/; reusedBy records
this new identity. The master is not claimed to have been generated again.

tokens/design-tokens.json is the color/spacing/type contract. Semantic revision 1.1
adds ink/cobalt native studio surfaces and a cooler light canvas; Mox and the
core identity colors are unchanged. Static ambient light and orbital accents
provide depth, while animation remains tied to real work.
Revision 1.2 records shared control insets and layout padding; colors are unchanged.
Normal text pairs in tokens/contrast-checks.json meet 4.5:1 in both themes.
Control/focus boundaries meet 3:1; card borders remain decorative.
The portable CSS export includes the local WOFF2 and its OFL license in fonts/.
Primary controls 44px; compact native secondary controls 36px. Radii8/12/16/24.
UI-KIT.md defines the production component system: shared action variants,
inputs, cards, control heights, padding, spacing and keyboard feedback.
Follow the OS light/dark preference; light is the deterministic fallback.
No idle animation. Keep real status labels and evidence/receipt behavior.

Native palette.rs is generated from the semantic JSON; package icons are copied
from these reviewed exports by scripts/build-studio-icons.swift.
Moxcrew uses stable patchfleet package, bundle, data and protocol identifiers.
A domain purchase does not mean the service is deployed there.
