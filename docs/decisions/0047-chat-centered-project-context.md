# ADR0047: Chat-centered Project context

Status: Accepted by owner choice; Task0048

Date: 2026-10-19

The owner selected a chat-centered, lightly futuristic product. Chat remains the
main Project work surface; Crew and Outputs provide contextual work beside it
when space permits. Narrow windows use a readable detail surface with an explicit
return to the same conversation. One state/command implementation serves both
layouts. Existing exact Project/hash/receipt and approval boundaries remain.

Keep the accepted native visual system and restrained state-driven motion.
This changes the UI hierarchy, not agent authority, provider configuration,
canonical data, external side-effect consent or the local/Cloud trust boundary.
