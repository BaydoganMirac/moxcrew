# Editable scenario workbooks

Updated: 2026-11-04

Status: Complete; locally verified

Plan: [Task0073](../plans/0073-editable-scenario-workbooks.md)

**Project tools → Create outputs → Scenario workbook** now accepts one available
Project CSV, a title, four exact columns in item/base/upside/downside order and a
three-letter currency. It stages the typed request in Chat; it does not send,
prepare or start work.

The local `data.scenario` worker requires a rectangular UTF-8 CSV with unique,
non-empty headers, 1–5,000 uniquely named items and finite scenario values in
the supported numeric range. It publishes nothing when a column, label, number,
shape or bound is invalid. No row is silently truncated.

One checked row set produces three matching outputs:

- `scenario.xlsx` opens on a Scenario Model sheet with a Base/Upside/Downside
  dropdown, editable Inputs sheet, fixed per-row formulas and an editable total.
  It requests automatic full recalculation on load and marks formula cells for
  recalculation; the worker reopens the package and checks every exact reference,
  the total formula, dropdown contract and calculation metadata before success.
- `scenario-data.json` records exact columns, item values, checked scenario
  totals, row/formula counts and currency without an owner path.
- `report.md` records the same three totals and escaped owner labels.

The operation uses Python's standard library only. Formulas are generated by
Moxcrew from fixed templates; owner text never becomes a formula, macro,
external link or workbook relationship.

## Limits

This is a deterministic three-scenario workbook, not forecasting, optimization,
accounting advice or a general formula authoring engine. Columns are not inferred;
item labels must be unique; macros, arbitrary formulas, live rates and external
workbook links are unsupported. Windows result access remains deferred to
Windows-PC verification.
