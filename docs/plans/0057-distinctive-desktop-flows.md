## Goal

Carry the deliberate Moxcrew workbench through Projects, Teams, Tasks, Memory,
Decisions, Agents, Providers, Account/Cloud and the existing Crew/Outputs paths.
Replace generic SaaS card grids and redundant chrome with content-shaped layouts,
plain action language and a consistent reading order without changing behavior.

## Direction

- Palette: ink `#090D18`, deck `#111827`, raised `#1B253A`, cobalt `#2854F4`,
  signal orange `#FF7A2F`, paper `#F2F5FF`.
- Type: Manrope only; 28/24 page, 20 section, 15/14 body, 12 metadata.
- Layout: page direction first, then the primary work surface, then contextual
  actions. Keep a left reading axis; use a right inspector only for selected
  detail or task creation.
- Structure: use flat ledgers for collections, a single band for aggregate state,
  and semantic stripes for source/state. Forms may retain bounded surfaces.
- Restraint: the Task0056 Mox launch pad remains the only high-energy brand
  moment. Other screens are bold through hierarchy and information structure,
  not gradients, glows, motion or a new card kit.

## Scope and acceptance

Update the shared non-Chat page header, empty states and collection surfaces;
then apply them to Projects, Memory sources, Decisions, Tasks, legacy coding
teams, Agents and Providers. Preserve Account/Cloud privacy boundaries and the
existing Crew/Outputs authority flow. Correct generated-design tells in affected
copy: decorative all-caps, middle-dot metadata and numbering that is not a real
sequence.

Add no dependency, backend contract, event/schema change, provider behavior,
automatic execution, Cloud mutation, installation or publication. Preserve
keyboard names/focus, Turkish/English, light/dark, 800x560 behavior, drafts,
exact revisions and explicit Prepare/Start/accept/publish authority.

Validation requires the all-feature desktop suite, strict workspace Clippy,
formatting, diff checks and native captures of every changed top-level route in
normal and representative minimum-window states. Visual acceptance remains the
owner's judgment.

The shared page header now establishes direction without a redundant breadcrumb,
and collections use flat semantic ledgers instead of repeated dashboard cards.
Projects gained one aggregate band and a project ledger; Memory, Decisions,
Tasks, coding teams, Agents, Providers and shared Cloud decisions use the same
source/state language. Quick Start, task creation and account setup retain
bounded, orange-signalled guidance because they are owner-input flows. Chat
shortcuts no longer carry decorative sequence numbers; actual Quick Start steps
retain numbering.

No Cloud source, core protocol, event/schema, provider behavior, automatic
execution, installation or publication changed. All 231 desktop tests pass,
strict workspace Clippy and formatting pass, and native evidence covers eight
normal routes plus four representative 800x560 light-theme routes. The captures
